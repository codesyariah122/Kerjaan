📘 Dokumentasi Web Developer Custom: Laravel, CodeIgniter & WordPress
🔧 Tools Pengembangan (Development Tools)
1. Code Editor / IDE
Nama	Fitur Utama
Visual Studio Code	Gratis, banyak extension, Git integration
Sublime Text	Ringan, cepat, banyak plugin
Xampp paket lengkap web server di local, PhpStorm	Powerful untuk PHP, built-in database tools & debugging
2. Version Control System
Tool	Fungsi
Git	Versi kode, kolaborasi tim
GitHub / GitLab / Bitbucket	Repositori online, CI/CD, issue tracker
3. Local Development Environment
Tool	Kelebihan
XAMPP / MAMP / WAMP	Mudah digunakan untuk pemula
Laragon	Ringan, portable, auto SSL, Composer support
Docker	Isolasi lingkungan, cocok untuk teamwork dan production mirror
LocalWP	Ideal untuk WordPress, UI friendly
4. Database Management
Tool	Deskripsi
phpMyAdmin	GUI web untuk MySQL/MariaDB
Adminer	Alternatif ringan dari phpMyAdmin
Sequel Ace / DBeaver / HeidiSQL	Native desktop app untuk mengelola database
5. Package Manager
Tool	Untuk
Composer	Mengelola dependensi PHP (Laravel, CI, WP plugin dev)
npm / yarn	Mengelola dependensi JavaScript & CSS frontend
Laravel Mix / Vite / Webpack	Build asset frontend (SCSS, JS, Vue, React, dll)
6. Testing & Debugging Tools
Tool	Kegunaan
Postman / Insomnia	Testing API
Xdebug	Debug PHP secara interaktif
PHPUnit / PestPHP	Unit test Laravel/CI
Laravel Telescope	Debug & log Laravel (query, request, dll)
Query Monitor (WordPress)	Profiling query dan hook WP
7. Deployment Tools
Tool	Fungsi
cPanel / FTP	Deploy manual ke shared hosting
Laravel Forge	Otomasi deploy Laravel ke VPS
GitHub Actions / GitLab CI/CD	Deploy otomatis setelah push
rsync / SCP / SFTP	Transfer file antar server
Cloud Hosting	DigitalOcean, Vultr, Linode, AWS, dll
8. Tools Tambahan
Tool	Fungsi
Ngrok / Localtunnel	Buka akses local server ke internet
Mailtrap / Mailhog	Testing pengiriman email lokal
Browsersync	Auto reload saat edit file
Sass / TailwindCSS / Bootstrap	Framework CSS untuk frontend
Figma / Zeplin	UI design, prototyping sebelum coding

Dengan toolset ini, kamu bisa bekerja secara efisien, terstruktur, dan scalable baik untuk proyek kecil maupun besar, baik Laravel, CodeIgniter, maupun WordPress.
